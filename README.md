# Eugine Sulumet Portfolio

Responsive personal portfolio for a Data Scientist & Data Analyst.

## Files
- `index.html` — portfolio structure/content
- `css/style.css` — responsive styling
- `js/script.js` — navigation, animations, scroll progress and interactions
- `images/` — add your photo and project screenshots here

## Before publishing
1. Replace `your.email@example.com` with your professional email.
2. Replace project `#` links with your GitHub repository links.
3. Replace the CV placeholder with your PDF link.
4. Add your photo to `images/` and update the profile section when ready.
5. Test the site on mobile and desktop.
